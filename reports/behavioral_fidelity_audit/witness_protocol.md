# Exploratory identifiability check

This supplement was specified after primary replay and before inspecting the witness counts. It does not alter the locked primary endpoints. For every F dataset, take every completed table already emitted by E1, E2, loop and loop+obs, collapse exact duplicates, filter by acceptance of all positives and by rejection of every negative for the specified arm (A has none; B legacy; C natural). For every initial CTL/LTL property retain the first lexicographic pair of eligible model IDs with opposite verdicts, if available. This is a sound lower bound on undecidable verdicts for the hypothesis class, with no completeness claim. No true successor, oracle verdict or confidence enters candidate eligibility or witness selection. nuXmv/CTL verdicts used here are checks of feasible candidate models. Never choose a reconstruction from these results. Separately recalculate all 36 version-space summaries and per-edge marginal supports with the existing exact algorithm.
